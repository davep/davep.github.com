I've just updated [Peplum](https://peplum.davep.dev/) to v1.1.0. For anyone
who might not have run into it before, Peplum is a simple terminal-based
browser and reader for Python PEPs. I first released it [in January last
year](/2025/01/25/peplum.html) and it's been pretty stable since. Earlier
today, though, I noticed it falling over due to an unexpected value in one
of the properties of a PEP.

![Peplum](/attachments/2026/10/29/peplum-1-1-0.webp#centre)

So this release fixes that issue. It also drops support for Python 3.10
(which is now end of life) and CI now also tests with Python 3.14 and 3.15.

Peplum can easily be installed with [uv](https://docs.astral.sh/uv/):

```sh
uv tool install peplum
```

Once installed, simply run `peplum`.
