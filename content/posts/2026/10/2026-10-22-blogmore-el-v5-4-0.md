I've just made a very small update to
[`blogmore.el`](https://github.com/davep/blogmore.el) to fix a small bug,
and also to update some deprecated code.

The `blogmore-new` command inserts the result of expanding a template into
the buffer when making a new post, and I've not touched that template since
I started writing `blogmore.el`. This includes not updating it when I
switched much of the frontmatter-handling code over to proper YAML parsing.
The problem here was that the title didn't get quotes around it, which
became an issue if there was something like a `:` in the title; any
subsequent attempt to modify frontmatter properties would throw an error.

So this release ensures that the title and the date get quoted right away. I
guess, at some point, I should rework this code so that it uses the
frontmatter-handling code to set up those properties and, instead, just uses
the template for the main body.

I've also changed all uses of things like `when-let` and `if-let` to use
`when-let*` and `if-let*`. It seems that, as of Emacs 31.1, the former are
deprecated.
