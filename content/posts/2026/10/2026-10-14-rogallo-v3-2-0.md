I've just bumped [Rogallo](https://rogallo.davep.dev/) to v3.2.0. This
release has one small new feature and one wee bug fix.

The new feature is something I found myself wanting a short while ago. I was
copying some URIs and then turning them back into [Gemtext](/tag/gemtext/)
links in another document; after doing that a few times, I realised that it
might be handy to extend the "copy URI" facility in the viewer so that
there's a "copy URI as Gemtext" version. To this end, I've added
`gemtext_link.copy_link_as_gemtext` as a [viewer widget
binding](https://rogallo.davep.dev/ui/viewer/#available-bindings), bound to
<kbd>Shift</kbd>+<kbd>c</kbd> by default.

The fix is a small one to how MIME type checks are done. In one particular
case, Rogallo wasn't stripping off any parameters where it should have. This
is now fixed.
