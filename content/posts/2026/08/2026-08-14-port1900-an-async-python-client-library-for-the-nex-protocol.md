It's that time again. Time to add another [small web
protocol](/tag/smolweb/) to [Rogallo](https://rogallo.davep.dev/). This time
it's one I stumbled across a few days ago: the [Nex
protocol](https://nightfall.city/nex/info/specification.txt). This one is
very simple and straightforward and it seemed like a shame *not* to support
it.

So, as I have with [Gemini](https://wasat.davep.dev/),
[Spartan](https://sybaritic.davep.dev/), [Gopher](https://port70.davep.dev/)
and [Finger](https://port79.davep.dev/), I've added a dedicated library for
dealing with the associated URI, and to provide a client for talking to the
server.

The documentation can be found on [the dedicated
site](https://port1900.davep.dev/).
