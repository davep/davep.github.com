Currently, I'm working on adding support for the [Nex
Protocol](/tag/nex-protocol/) to [Rogallo](https://rogallo.davep.dev/).
Having
[Port1900](/2026/08/14/port1900-an-async-python-client-library-for-the-nex-protocol.html)
as the client library, and having [done the bulk of the work in
Rogallo](https://github.com/davep/rogallo/pull/345), I needed things in
place to be able to add some `nex://`-related documentation too -- which is
where [SmolServe](https://smolserve.davep.dev/) comes in.

So I've dropped [v1.1.0](https://smolserve.davep.dev/changelog/#v110) on
[PyPI](/tag/pypi/), which adds support for running up a simple
just-good-enough Nex server (although, to be fair, Nex is *so* simple this
is probably a fully capable one just by the very nature of how trivial the
protocol is).

Now to get back to polishing that Rogallo PR...
