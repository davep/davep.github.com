I've released a small update to [Gemtext](https://gemtext.davep.dev/). At
the moment, I'm working on adding [Spartan
protocol](https://portal.mozz.us/spartan/spartan.mozz.us/) support to
[Rogallo](https://rogallo.davep.dev/), and to do this I need to handle a
small extension it makes to Gemtext.

While Spartan is quite different from Gemini in the underlying protocol, it
uses Gemtext as the default/standard markup language, but with one small
difference. To allow uploaded data that is initiated by the markup, rather
than by the server, there is a `=:` line type. In some respects, this is
similar to type `7` items in Gopher maps.

Rather than spin up a whole new library just to support this one small
difference, and rather than do some special-case nonsense in Rogallo itself,
I've added optional (and turned on by default) support for `=:`. When
encountered, this results in a
[`SpartanPrompt`](https://gemtext.davep.dev/gemtext/#gemtext.SpartanPrompt)
object, which simply inherits from a
[`Link`](https://gemtext.davep.dev/gemtext/#gemtext.Link).

Any code that doesn't require this feature can turn it off with the
[`with_spartan_support`
parameter](https://gemtext.davep.dev/gemtext/#gemtext.Gemtext(with_spartan_support)).
