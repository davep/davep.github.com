After a short break [to do some fossil
hunting](/2026/08/02/fossil-hunting-in-whitby.html), I'm back tinkering with
[Rogallo](https://rogallo.davep.dev/). The main change in
[v1.5.0](https://rogallo.davep.dev/changelog/#v150) is the addition of
[support for custom themes](https://rogallo.davep.dev/custom-themes/).

Before I get to that though, there's a small number of other fixes,
additions and tweaks. The first is a small change to the Gopher support. As
of this version, if there's a type `8` item in a Gopher menu, it will now be
turned into a `telnet://` URI rather than being left as a `gopher://` URI.
This should help in handing off such an item to the correct application in
your environment.

I've also added a new command: `PipeDocument`. This is bound to
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>p</kbd> by default. If you're viewing
a document and run this command, you'll be prompted for a shell command that
the source of the document will be piped through. This could be useful for
transforming the source and passing it on elsewhere. For example:

![Piping a document](/attachments/2026/08/05/pipe-document.webp#centre)

One small fix in this release is the correction of a typo in the code that
resulted in a misspelled item in the configuration file. The
`bookmarks_visble` configuration setting has been changed to
`bookmarks_visible` (the spelling of *visible* was wrong). Technically this
is a breaking change but, because the impact is almost zero, I'm running
with it. The worst possible outcome after installing v1.5.0 is that the
bookmarks aren't showing in the sidebar when they were before; calling them
back up will fix the issue.

Now on to the main change: custom themes. Rogallo has always had theme
support, and the themes that were made available were most of the themes
built into [Textual](/tag/textual/). There [was a
request](https://github.com/davep/rogallo/discussions/225) to be able to
create additional themes, and so, [here's that
feature](https://rogallo.davep.dev/custom-themes/). Using this, if you want
to have Rogallo look *just so*, you can now follow the documentation, or
look over the
[examples](https://github.com/davep/rogallo/tree/main/example-themes), and
have a play. So if you fancied a version of Rogallo that looked like it was
running on a good old green terminal:

![Green example theme](/attachments/2026/08/05/green.webp#centre)

Or perhaps an amber terminal is more your thing?

![Amber example theme](/attachments/2026/08/05/amber.webp#centre)

Maybe you hanker after the days of MS-DOS and those Turbo IDEs?

![Something more Turbo](/attachments/2026/08/05/turbo.webp#centre)

Even better: perhaps the CBM64 was your thing back in the day?

![A theme that evokes the CBM64](/attachments/2026/08/05/cbm64.webp#centre)

Note that none of these themes are part of Rogallo itself, and don't ship
*with* it; they're just examples of what you could do if you wished. I don't
even offer them as good examples of what you could do (for example: I can
see that I've managed to end up with the jump labels being far too dim to be
readable). I'm sure other people with more talent for design than I have
will be able to do far better. If anyone wants to make their own themes and
share them, I've [created a spot just for
that](https://github.com/davep/rogallo/discussions/categories/custom-themes).

One last thing: while it's not a feature of this version of Rogallo, I've
also done some work on [the site](https://rogallo.davep.dev/) to try and add
a little more detail about using Rogallo. This process will be ongoing. The
main additions here are some background on [the supported
protocols](https://rogallo.davep.dev/protocols/) and [some help on the key
UI elements](https://rogallo.davep.dev/ui/).

The documentation is also greatly improved with better examples thanks to
[smolserve](https://smolserve.davep.dev/) -- this is a little helper project
I've been tinkering with. Note that this is *not* and will never be intended
to be an actual small web server; it is and always will be a tool to help
development and to support [the production of Rogallo's
documentation](https://github.com/davep/rogallo/tree/main/docs).
